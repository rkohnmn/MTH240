# Assignment 08: Complete Induction and Relations

Homework assignment for MTH 240 covering complete induction and basic relation properties.

## Contents

- Complete induction: $n = 3s + 4t$ ($n > 22$) and $n = 4s + 5t$ ($n > 33$)
- Second-order linear recurrence relation ($a_{n+2} = 5a_{n+1} - 6a_n$)
- Strong induction on Fibonacci powers ($g_n = 2^{f_n}$)
- Relation inverses and domains of composition ($\mathrm{Dom}(S \circ R) \subseteq \mathrm{Dom}(R)$)
- Number of relations between finite sets ($2^{mn}$)
