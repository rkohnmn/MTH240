# Assignment 11: Functions and Modular Arithmetic

Homework assignment for MTH 240 covering function properties and modular arithmetic mappings.

## Contents

- Domain restrictions and inverses
- Restriction composition identity ($f = g \circ i_D$)
- Product mappings ($f \times g: A \times C \to B \times D$)
- Surjectivity and injectivity of functions on $\mathbb{Z}_4$ and $\mathbb{Z}_2$
