# Selected Problem Sets

Selected homework assignments from MTH 240 (Transition to Abstract Mathematics) at Muhlenberg College.

## Assignments

- [Assignment 08](assignment-08-induction-and-relations/) — Complete induction, linear recurrence relations, and relation composition domains.
- [Assignment 11](assignment-11-functions-and-modular-arithmetic/) — Function restrictions, Cartesian product mappings, and modular arithmetic functions.
- [Assignment 12](assignment-12-bijections-and-permutations/) — Proof of bijectivity on a rational function and cycle notation in $S_7$.
